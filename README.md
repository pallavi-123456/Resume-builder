# 🤖 AI Resume Builder & Analyzer

An AI-powered Full Stack MERN application that enables users to build professional resumes, analyze resume quality using AI, improve ATS compatibility, and export resumes in a clean, modern format.



## ✨ Features

- 🔐 Secure User Authentication (JWT)
- 📝 Interactive Resume Builder
- 🤖 AI Resume Analysis
- 📊 ATS Resume Score
- 💡 AI Suggestions & Improvements
- 🎯 Skills Recommendation
- 📄 PDF Resume Download
- 👀 Live Resume Preview
- 📱 Fully Responsive Design
- 🌙 Dark Mode Support
- ⚡ Fast & Modern UI



## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Framer Motion
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

- Google Gemini API
